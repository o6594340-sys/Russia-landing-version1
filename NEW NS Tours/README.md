# NEW NS Tours — Georgia Pitch Deck

Презентация для NS Tours: продать корпоративному клиенту тимбилдинг-программу в Грузии (Тбилиси и окрестности). По итогам просмотра клиент должен захотеть выбрать эту программу — яркую, самобытную, с живым участием гостей.

Не путать с соседней папкой `NS tours-presentation` — это более ранний, отдельный заход через Codex с другой концепцией и палитрой; сюда не переносим и не копируем.

## Две концепции

**Концепция 1 — «Тбилисская Вывеска 2.0».** Тёплый грузинский минимализм в духе вывесок и рукописных заметок. Молочный фон, гранатовый/шафрановый/изумрудный акценты, шрифты Unbounded + Manrope + Cormorant Garamond. Фото только на 4 из 10 слайдов, в масках (вывеска / арка / табличка / штамп). Подтверждена клиентом, зафиксирована — менять без явного запроса не нужно.

**Концепция 2 — «Гравюра на ярком».** Яркие насыщенные диагональные цветовые поля (терракотовый/горчичный/бирюзовый/сливовый), чёрная line-art графика в духе гравюры, текст на «карточке»-программке, рукописные заметки на полях, фото-полароид на скотче на каждом слайде. Шрифты Yeseva One + Caveat + Manrope. **Текущий фаворит клиента — основная линия работы.**

Обе используют один и тот же текст из `slides_copy_ru.md`, чтобы можно было сравнивать один в один.

## Статус и открытые вопросы

Прошла экспертное ревью (арт-дирекшн / UX / B2B-продажи), правки первого раунда внесены в Концепцию 2. Открыто, решение за клиентом:

1. **Модель цены** — единый пакет с одной ценой за 10-сценовый маршрут, или меню из 5 отдельных программ на выбор (как в исходном docx, с ценами $160/$140/$310/$175/$210 за человека)?
2. Длительность поездки (дней) и размер группы (мин/макс) — не указаны, нужны для реального КП.
3. Call-to-action на финальном слайде — сейчас заканчивается эмоциональной фразой без контакта/кнопки «запросить расчёт».
