# CLAUDE.md — NEW NS Tours

This file provides guidance to Claude Code when working in this repository.

## Project

Pitch-deck for a Georgia corporate team-building trip, sold by DMC "NS Tours" to corporate MICE clients. Two parallel HTML deck concepts live in `decks/` — self-contained single-file HTML (fonts + photos embedded as base64 data URIs, no external requests, no build step). Source copy for both is `slides_copy_ru.md` (10 scenes, Russian).

## Rules

- **Never reference or copy from `../NS tours-presentation`.** That's a separate, earlier Codex-built deck (concept "Georgia at Full Volume", 5 modular priced programs) that the client explicitly rejected. Do not pull its design, palette, or copy into this project. The only thing that folder is allowed to contribute is the raw source photography in `assets/user-gallery/` (the client's own photos) — reading/reusing those images is fine, its *design* is not.
- **Concept 1 (`decks/concept1-tbilisi-signboard.html`) is locked.** Client confirmed it — don't change palette (`#F7F1E8` milk / `#B8323C` garnet / `#F2A33A` saffron / `#1F8A70` emerald / `#2E2A27` graphite / `#E8D8BF` sand), fonts (Unbounded / Manrope / Cormorant Garamond), or the "photo only on slides 1/5/7/10, masked as signboard/arch/plaque/stamp" discipline unless explicitly asked. Full spec: `presentation_style_guide_ru.md`.
- **Concept 2 (`decks/concept2-engraving-bright.html`) is the active line of work** — client prefers it. Design tokens: bright diagonal duotone fields per slide (`--rust #D2481F`/`#E85A2C`, `--mustard #E2A317`/`#F0B928`, `--teal #0F9C82`/`#17B294`, `--grape #8B3F6B`/`#A9477F`, each as a `linear-gradient(112deg, light 0 57%, dark 57% 100%)`), ink-line "engraving" doodle per slide, rotated parchment `.card` (`#FBF3E0`) styled like a torn program page, Polaroid-style `.postcard` photo taped on every slide, handwritten `.note` in the margin (must NOT restate the `.humor` line — give it a distinct fact/detail instead). Fonts: Yeseva One (headlines) + Caveat (handwritten) + Manrope (body). Both are variable/static Google Fonts fetched once and cached as base64 in a scratchpad `fonts2/` folder during a session — if you need to re-touch the HTML, the template with `__PLACEHOLDER__` tokens plus the substitution script are NOT persisted in this repo (they lived in session scratchpad); re-fetch fonts from `fonts.googleapis.com/css2?family=...` with a Chrome-like `User-Agent` (needed for woff2 + correct cyrillic subset) if starting fresh.
- **No pricing decision has been made.** Original `text for presentation.docx` had 5 separately-priced programs ($160/$140/$310/$175/$210 per person). The approved `slides_copy_ru.md` currently presents all 10 scenes as ONE continuous trip with no prices shown. Don't invent or restore prices without asking — this is explicitly an open decision for the client.
- **QA any HTML slide edit visually before calling it done.** A local Playwright/Chromium install exists at `%LOCALAPPDATA%\ms-playwright` (or reinstall via `npx playwright install chromium` into a throwaway npm project). Both decks support `?slide=N` in the URL to jump straight to a slide for screenshotting — use `npx playwright screenshot --viewport-size=1600,1000 --wait-for-timeout=1000 "file:///<path>?slide=N" out.png`. Card/photo/note layering has previously broken when body-text length grew past 3 lines and pushed the centered card up into the top-margin handwritten note — check for that specifically after any copy change.
- Both decks are pure vanilla HTML/CSS/JS — no dependencies, no build. Edit in place, no compilation step.
