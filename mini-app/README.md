# Деловой форум Пекин 2024 — Event Mini-App

PWA для корпоративного инсентив-тура: программа форума + мини-гид по Пекину.  
Участники открывают на телефоне как сайт или устанавливают на экран (PWA).  
Организатор управляет контентом через отдельную панель администратора.

---

## Структура

```
app/
├── index.html        # Сайт участника
├── admin.html        # Панель организатора (пароль: forum2024)
├── manifest.json     # PWA-манифест
├── sw.js             # Service Worker (офлайн-кэш)
├── css/
│   ├── main.css      # Стили участника
│   └── admin.css     # Стили панели
└── js/
    ├── data.js       # Все данные по умолчанию
    ├── app.js        # Логика сайта участника
    └── admin.js      # Логика панели администратора
```

## Панель администратора

Открывается по `/admin.html`, защищена паролем.

Разделы:
- **Объявление** — баннер вверху сайта участника (info / warning / success)
- **Настройки события** — название, даты, Wi-Fi, контакты организатора, отель
- **Программа** — CRUD активностей по дням
- **Деловая часть** — CRUD сессий (день, трек, спикеры, зал)
- **Отель** — основная информация, удобства (CRUD), советы
- **Достопримечательности** — CRUD мест
- **Рестораны** — CRUD ресторанов
- **Кухня** — CRUD блюд с флагом «Маст»
- **История** — CRUD фактов по разделам с флагом «🤯»

## Хранение данных

Данные по умолчанию — в `data.js` (константы `EVENT`, `HOTEL`, `DAYS`, `BUSINESS_SESSIONS`, `SIGHTS`, `RESTAURANTS`, `CUISINE`, `HISTORY`, `FAQ`).

Изменения из панели сохраняются в **localStorage** под ключами `admin_*`.  
Сайт участника читает localStorage и берёт данные администратора, если они есть.

Ключи:
```
admin_announcement   admin_event   admin_days    admin_business
admin_hotel          admin_sights  admin_restaurants
admin_cuisine        admin_history
```

> Оба файла (`index.html` и `admin.html`) должны лежать на **одном домене** — иначе localStorage не шарится.

## Деплой

Статический сайт — никакого сервера не нужно. Достаточно загрузить папку `app/` на любой хостинг.

Рекомендуемые варианты для РФ:
- **Beget / TimeWeb / REG.RU** — дёшево, поддержка на русском
- **Selectel / Yandex Cloud** — надёжность + CDN
- **GitHub Pages** — бесплатно

Загрузить папку `app/` в корень сайта. Файл `index.html` открывается по умолчанию, `admin.html` — по прямой ссылке (участникам не показывать).

## Кастомизация под другое событие

1. Отредактировать константы в `data.js` (или через панель администратора)
2. В `manifest.json` обновить `name`, `short_name`, `theme_color`
3. В `index.html` обновить `<title>` и заголовок в шапке
