# Деловой форум Пекин 2024 — Event Mini-App

PWA для корпоративного инсентив-тура: программа форума + мини-гид по Пекину.  
Участники открывают на телефоне как сайт или устанавливают на экран (PWA).  
Организатор управляет контентом через отдельную панель администратора.

---

## Структура

```
app/
├── index.html        # Сайт участника
├── admin.html        # Панель организатора (пароль: forum2024)
├── manifest.json     # PWA-манифест
├── sw.js             # Service Worker (офлайн-кэш)
├── css/
│   ├── main.css      # Стили участника
│   └── admin.css     # Стили панели
└── js/

    ├── app.js        # Логика сайта участника
    └── admin.js      # Логика панели администратора
```

## Панель администратора

Открывается по `/admin.html`, защищена паролем.

### PRO — оформление

| Раздел | Что делает |
|---|---|
| 🎨 **Brand Kit** | Сохранить набор настроек как пресет, применить к событию одним кликом |
| ✨ **Анимации** | Swift (быстро) / Elegant (плавно, ease-out) / Minimal (только fade) |
| 🃏 **Стиль карточек** | Elevated (тень) / Flat (без тени) / Glass (blur) / Outlined (рамка акцента) |
| 🎨 **Градиент** | 5 рецептов: Glow / Diagonal / Vertical / Mesh / Flat — для шапки и NOW-блока |
| 🔤 **Типографика** | 5 шрифтовых пар: Modern / Executive / Editorial / Friendly / Tech |
| 🖌 **Цвет бренда** | Hex-пикер + авто-генерация hover/muted/shadow из одного цвета |
| 🖼 **Логотип** | Загрузка файла или URL, отображается в шапке приложения |

### Импорт программы

Раздел **📥 Импорт программы** — вставить текст по шаблону, одна кнопка, готово. Никаких внешних сервисов.

Формат:
```
День 1 | 18 ноября, понедельник
09:00 | Завтрак в ресторане отеля
11:00 | Деловая: Открытие форума
13:00 | Обед
```

Разделители `|` и `—` поддерживаются. Строки с `Деловая:` автоматически попадают в деловую часть. Тип активности определяется по ключевым словам (завтрак/обед/ужин → meal, трансфер → transfer, экскурсия → excursion).

### Контент

- **Объявление** — баннер вверху сайта участника (info / warning / success)
- **Настройки события** — название, даты, Wi-Fi, контакты организатора, отель
- **Программа** — CRUD активностей по дням
- **Деловая часть** — CRUD сессий (день, трек, спикеры, зал)
- **Отель** — основная информация, удобства (CRUD), советы
- **Достопримечательности** — CRUD мест
- **Рестораны** — CRUD ресторанов
- **Кухня** — CRUD блюд с флагом «Маст»
- **История** — CRUD фактов по разделам с флагом «🤯»

### Данные

- **Шаблон страны** — загрузить контент по направлению (Пекин / Токио / Дубай / Бангкок / Стамбул)
- **Бэкап** — экспорт всех данных в JSON, импорт из файла

## Хранение данных

Данные по умолчанию — в `data.js` (константы `EVENT`, `HOTEL`, `DAYS`, `BUSINESS_SESSIONS`, `SIGHTS`, `RESTAURANTS`, `CUISINE`, `HISTORY`, `FAQ`).

Изменения из панели сохраняются в **localStorage** под ключами `admin_*`.  
Сайт участника читает localStorage и берёт данные администратора, если они есть.

Ключи:
```
# Контент
admin_announcement   admin_event   admin_days    admin_business
admin_hotel          admin_sights  admin_restaurants
admin_cuisine        admin_history

# PRO-оформление
admin_typography     admin_gradient   admin_card_style
admin_motion         admin_brand_kits
```

> Оба файла (`index.html` и `admin.html`) должны лежать на **одном домене** — иначе localStorage не шарится.

## Деплой

Статический сайт — никакого сервера не нужно. Достаточно загрузить папку `app/` на любой хостинг.

Рекомендуемые варианты для РФ:
- **Beget / TimeWeb / REG.RU** — дёшево, поддержка на русском
- **Selectel / Yandex Cloud** — надёжность + CDN
- **GitHub Pages** — бесплатно

Загрузить папку `app/` в корень сайта. Файл `index.html` открывается по умолчанию, `admin.html` — по прямой ссылке (участникам не показывать).

## Дизайн

- Цвет акцента: `#C9353F` (пекинский красный)
- Фон: `#FDFAF6` (тёплый белый)
- Шрифты: Inter (интерфейс) + Poppins (заголовки) — Google Fonts
- PWA: `theme-color`, `manifest.json`, Service Worker с офлайн-кэшем

### PRO-кастомизация (май 2026)

Система **constrained customization** — организатор выбирает параметры, система гарантирует профессиональный результат.

- **Brand Kit** — сохранить весь набор настроек оформления как именованный пресет, применять к будущим событиям в один клик
- **Градиентные рецепты** — 5 рецептов (Glow / Diagonal / Vertical / Mesh / Flat) применяются к шапке и NOW-блоку; цвета деривируются из единого brand color
- **Стиль карточек** — 4 варианта через body-классы (`cs-flat`, `cs-glass`, `cs-outlined`); Glass использует `backdrop-filter: blur(14px)`
- **Типографика** — 5 кураторских шрифтовых пар (Modern/Executive/Editorial/Friendly/Tech); шрифты подгружаются из Google Fonts динамически
- **Анимации** — Swift (0.25s ease) / Elegant (0.4s expo-out + глубокий слайд) / Minimal (0.15s fade); управляются CSS-переменными `--motion-*`

### UX-улучшения (май 2026)

- **Таб-бар:** правый край плавно уходит в белый (`mask-image`) — видно что вкладок больше
- **Touch targets:** минимум 44px на всех кнопках-вкладках (соответствует Apple HIG и Material)
- **GPU-анимации:** `pulseLive` и `pulseDot` переведены с `box-shadow` на `transform + opacity` через псевдоэлементы — не вызывают repaint
- **NOW-блок:** полный акцентный градиент, белый текст 20px/800, min-height 110px — главный элемент экрана «Сегодня»
- **WiFi:** перемещён выше таймлайна (сразу после NOW/NEXT — туда где нужен при первом открытии)
- **Совет дня:** фиксируется через `sessionStorage`, не меняется при переключении вкладок

## Кастомизация под другое событие

1. Отредактировать константы в `data.js` (или через панель администратора)
2. В `manifest.json` обновить `name`, `short_name`, `theme_color`
3. В `index.html` обновить `<title>` и заголовок в шапке
