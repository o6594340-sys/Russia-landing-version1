# Мажордом 💰

Личный финансовый мажордом — показывает сколько денег реально свободно после всех обязательных платежей.

## Что умеет

- **Главный экран** — цитата дня + одна цифра "Свободно сейчас" (баланс минус все незакрытые платежи месяца)
- **Доходы** — фиксировать поступления по счетам
- **Расходы** — разовые и регулярные платежи
- **Календарь** — все платежи месяца с галочками оплаты
- **Счета** — несколько карт/счетов, обновление баланса вручную
- **Цели** — прогресс-бар с дедлайном (например, ремонт 600 000 ₽ до июля)
- **Настройки** — управление регулярными платежами и целями

## Запуск локально

```bash
cd EXPENCES
pip install flask
python app.py
```

Открыть в браузере: http://localhost:5000

## Деплой на Railway

> Перед деплоем на Railway нужно перейти с SQLite на PostgreSQL — иначе данные будут сбрасываться. Обратись к разработчику.

1. Railway → New Project → Deploy from GitHub
2. Выбрать репозиторий `Russia-landing-version1`
3. Root Directory: `EXPENCES`
