# Tozai Tours — Генератор КП (Япония)

Веб-приложение для автоматической генерации коммерческих предложений по корпоративным турам в Японию.
Генерирует презентацию PPT + смету Excel через 3-шаговый интерфейс.

---

## Запуск локально

Двойной клик на `start.bat` → открыть браузер: `http://localhost:5000`

Для показа клиентам из той же Wi-Fi сети: `http://192.168.31.70:5000`

---

## Деплой (Railway)

Приложение задеплоено на Railway: **russia-landing-version1-production.up.railway.app**

Для деплоя на новый аккаунт:
1. Railway → New Project → GitHub Repo → выбрать репозиторий
2. Settings → Root Directory → `Comercial-proposals`
3. Variables → добавить `ANTHROPIC_API_KEY`
4. Deploy

**Стоимость генерации:** ~$0.30–0.40 за одну презентацию (claude-opus-4-6).

---

## Флоу (3 шага)

1. **Заполнить форму** — вручную или загрузить бриф (PDF/Word) → автозаполнение через Claude
2. **Утвердить программу** — Claude генерирует черновик по дням, можно скорректировать
3. **Скачать файлы** — Excel-смета и PPT-презентация

## Маршруты

В брифе выбирается маршрут и города прилёта/вылета (open-jaw). Доступные маршруты:

| Ключ | Маршрут | Мин. дней |
|------|---------|-----------|
| `tokyo` | Только Токио | 2 |
| `tokyo_hakone` | Токио + Хаконэ | 4 |
| `tokyo_kyoto` | Токио + Киото | 5 |
| `tokyo_kyoto_nara` | Токио + Киото + Нара | 6 |
| `tokyo_hakone_kyoto` | Токио + Хаконэ + Киото | 6 |
| `tokyo_hakone_kyoto_nara` | Токио + Хаконэ + Киото + Нара | 7 |

Claude строит программу с учётом логистики переездов (Синкансэн, Romancecar) и указывает город каждого дня в скобках.

## Презентация PPT

### Дизайн: Washi & Red
- Фон: тёплый беж `#F7F4EF`
- Акцент: японский красный `#C8102E`
- Золото: `#A8895A`
- Тёмный (титул/финал): `#1A0A0D`
- Шрифты: Georgia (заголовки) + Arial (текст)

### Слайды
1. **Титул** — сезонное фото, название компании, параметры группы, маршрут (ТОКИО · КИОТО · НАРА, размер шрифта адаптируется под количество городов)
2. **Почему Япония** — 5 точек, персонализированных под отрасль и сезон группы
3. **Концепция** — идея тура под конкретную аудиторию
4. **Обзор программы** — тайминг по дням: маршрут в заголовке, время красным, золотые разделители утро/день/вечер
5. **Дни программы** — три чередующихся лейаута:
   - А: фото на весь экран, шапка сверху, расписание 3 колонки снизу
   - Б: без фото, три колонки с цветными шапками на бежевом фоне
   - В: фото верхние 55%, тёмная панель снизу с расписанием
6. **Хайлайты** — 3 (туры до 5 дней) или 4–5 (длинные туры), три вёрстки
7. **Размещение** — один или два слайда (Опция А / Опция Б)
8. **Финал / Контакты**

### Персонализация слайда "Почему Япония"

Пункты подбираются под отрасль и сезон группы:

| Отрасль | Акцент |
|---------|--------|
| IT / tech | Инженерная культура, TeamLab, Синкансэн |
| Фарма / медицина | Онсэн, кухня долголетия, велнес |
| Банки / финансы | Церемониальность этикета, протокол |
| Ритейл | Исэтан, Гиндза Сикс, стандарт сервиса |

Сезонный пункт заменяет базовый при весне / осени / зиме / лете.

### Фото для слайдов дней

Фото подбирается по содержимому дня, а не по номеру слайда. Приоритет:

1. **Конкретная активность** — мастер-класс суши, каллиграфия, тайко, омакасе, тэппаньяки, гала-ужин, кимоно, кабуки, майко и др. (40+ активностей)
2. **Конкретная локация** — Кинкакудзи, Фусими Инари, Арасияма, Асакуса и др.
3. **Город** — Киото, Нара, Осака, Хаконэ, Токио
4. **Сезон** — добавляется только к природным сценам (сакура, момидзи, снег)

Город и сезон добавляются как уточнение, но не управляют запросом если найдена активность.

### Генерация текстов — два вызова Claude

**Шаг 1 — структура** (`generate_program`): тайминг по дням (3–5 слов на строку, без эпитетов). Быстро, для обсуждения с менеджером.

**Шаг 3 — тексты** (`enrich_texts`): второй вызов по утверждённой программе. Генерирует:
- `concept_title` / `concept_text` — идея тура
- `day_descriptions` — вводная фраза для каждого дня (1–2 предложения, атмосфера, не тайминг)
- `hotel_description` — описание отеля
- `highlights` — хайлайты с photo_query
- `closing_note` — финальный образ

### Стиль текстов

**Аудитория:** директора, HR-руководители, люди летавшие бизнес-классом. Тон: 70% интеллектуальный текст, 30% мягкое «хочу поехать».

**Запрещено:** «незабываемый», «уникальный», «погружение», «магия», «адреналин», пафос, восклицания.

**Разрешено:** тихие точные образы, факты с цифрами, короткие предложения.

**Пунктуация:** тире только в определениях и расписании. Никаких тире вместо запятой.

## Фотобанк

Папка `photo_bank/` — локальные фото в приоритете перед Unsplash/Pexels.

**Как добавить фото:**
1. Скачать фото (JNTO, официальные источники)
2. Положить в папку `photo_bank/`
3. Добавить запись в `photo_bank/index.json`:

```json
{
  "file": "имя_файла.jpg",
  "tags": ["тег1", "тег2", "тег3"],
  "credit": "источник"
}
```

**Текущие фото в банке:**

## Смета Excel

### Как формируются сервисы

Смета строится по утверждённой программе, а не по шаблону. Логика `service_extractor.py`:

1. Для каждого дня читается текст `morning` / `afternoon` / `evening`
2. По ключевым словам определяются платные позиции:
   - Гид + Автобус — каждый день (кроме дня только с трансфером)
   - Трансфер — день 1 (из аэропорта) и последний день (в аэропорт)
   - Обед / Ужин — если упомянуты в программе
   - Ужин для гида — автоматически вместе с гидом
   - TeamLab, Синкансэн, мастер-классы, чайная церемония — по названию в тексте
   - Конференц-блок — в день конференции
3. Цена берётся из `Japan-rates-sample.xlsx`. Если цены нет — ставится 0 с пометкой «цена уточняется»

### Как добавить цены на новые сервисы

Открыть `Japan-rates-sample.xlsx`, добавить строку с названием и ценой. Система подхватит автоматически.

### Опциональные позиции

- **Отель Б** — золотой заголовок «ОПЦИЯ Б», количество ночей = 0, в ИТОГО не идёт. Менеджер ставит нужное количество ночей вручную.
- **Дополнительные опции** — раздел «Прочее» внизу сметы, в общий итог не включается.
- Одна итоговая сумма и одна цена на человека — по основной программе с отелем А.
