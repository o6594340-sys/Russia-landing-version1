# Tozai Tours — Генератор КП (Япония)

Веб-приложение для автоматической генерации коммерческих предложений по корпоративным турам в Японию.
Генерирует презентацию PPT + смету Excel через 3-шаговый интерфейс.

---

## Запуск

Двойной клик на `start.bat` → открыть браузер: `http://localhost:5000`

Для показа клиентам из той же Wi-Fi сети: `http://192.168.31.70:5000`

---

## Флоу (3 шага)

1. **Заполнить форму** — вручную или загрузить бриф (PDF/Word) → автозаполнение через Claude
2. **Утвердить программу** — Claude генерирует черновик по дням, можно скорректировать
3. **Скачать файлы** — Excel-смета и PPT-презентация

## Маршруты

В брифе выбирается маршрут и города прилёта/вылета (open-jaw). Доступные маршруты:

| Ключ | Маршрут | Мин. дней |
|------|---------|-----------|
| `tokyo` | Только Токио | 2 |
| `tokyo_hakone` | Токио + Хаконэ | 4 |
| `tokyo_kyoto` | Токио + Киото | 5 |
| `tokyo_kyoto_nara` | Токио + Киото + Нара | 6 |
| `tokyo_hakone_kyoto` | Токио + Хаконэ + Киото | 6 |
| `tokyo_hakone_kyoto_nara` | Токио + Хаконэ + Киото + Нара | 7 |

Claude строит программу с учётом логистики переездов (Синкансэн, Romancecar) и указывает город каждого дня в скобках.

## Сезонность

Система определяет сезон по строке с датами и передаёт его в промпт Claude и в выбор обложки:

| Сезон | Месяцы | Особенности |
|-------|--------|------------|
| Весна | март–май | Сакура, много туристов |
| Лето | июнь–август | Жарко, фестивали, зелень |
| Осень | сентябрь–ноябрь | Момидзи (красные клёны), лучший сезон |
| Зима | декабрь–февраль | Снег, онсэн, тишина |

## Презентация PPT

### Дизайн: Washi & Red
- Фон: тёплый беж `#F7F4EF`
- Акцент: японский красный `#C8102E`
- Золото: `#A8895A`
- Тёмный (титул/финал): `#1A0A0D`
- Шрифты: Georgia (заголовки) + Arial (текст)

### Слайды
1. **Титул** — сезонное фото на весь экран, название компании, параметры группы, open-jaw маршрут
2. **Почему Япония** — 5 конкретных фактов без воды
3. **Концепция** — идея тура под конкретную аудиторию
4. **Обзор программы** — схематичный тайминг всех дней: колонки по дням, секции утро/день/вечер с временами и названиями активностей
5. **Дни программы** — три чередующихся лейаута:
   - А: фото на весь экран, шапка сверху, расписание 3 колонки снизу
   - Б: тёмная панель слева (заголовок + расписание), фото справа
   - В: фото верхние 55%, чистая тёмная панель с расписанием снизу
6. **Хайлайты** — 3–4 витринных слайда, три чередующихся вёрстки:
   - А: фото справа, текст слева
   - Б: фото слева, текст справа
   - В: фото на весь экран, плашка снизу (текст в две колонки)
7. **Размещение** — описание отелей
8. **Финал / Контакты**

### Генерация текстов — два вызова Claude

**Шаг 1 — структура** (`generate_program`): только тайминг и названия дней. Быстро, для обсуждения с менеджером.

**Шаг 3 — тексты** (`enrich_texts`): второй вызов по утверждённой программе. Генерирует концепцию, описания дней, хайлайты. Качество выше, потому что Claude сосредоточен только на тексте, без структурных задач.

### Стиль текстов (зафиксирован в промпте)

**Аудитория:** директора, HR-руководители, люди летавшие бизнес-классом. Тон: сдержанное восхищение, негромкое изящество.

**Запрещено:**
- Физически грубые образы: «ритм бьёт в рёбра», «адреналин», «драйв»
- Пафос и восклицания
- Штампы: «сердце города», «перенесёт в другую эпоху», «магия»
- Слова: «незабываемый», «уникальный», «погружение», «впечатления», «атмосфера» без конкретики

**Разрешено:**
- Тихие точные образы: свет, тишина, запах, пауза
- Факты с цифрами: «230 мишленовских ресторанов», «1300 лет»
- Короткие предложения, дающие паузу

**Пунктуация:** тире только в определениях («X — это Y») и расписании («09:00 — завтрак»). Никаких тире вместо запятой.

## Фотобанк

Папка `photo_bank/` — локальные фото в приоритете перед Unsplash/Pexels.

**Как добавить фото:**
1. Скачать фото (JNTO, официальные источники)
2. Положить в папку `photo_bank/`
3. Добавить запись в `photo_bank/index.json`:

```json
{
  "file": "имя_файла.jpg",
  "tags": ["тег1", "тег2", "тег3"],
  "credit": "источник"
}
```

**Текущие фото в банке:**

| Файл | Теги |
|------|------|
| `Kinkakuji.jpg` | kyoto, temple, traditional |
| `Maiko.jpg` | maiko, geisha, performance |
| `young maiko - 2 persons.jpg` | maiko, gala, entertainment |
| `maiko performace.jpg` | maiko, show, kabuki |
| `Momiji-Kyoto.jpg` | kyoto, autumn, temple |
| `Momiji-fuji.jpg` | fuji, autumn, landscape, cover |
| `momiji-Tokyo.jpg` | tokyo, autumn, street |
| `Nara park.jpg` | nara, deer, nature |
| `Shinkansen.jpg` | shinkansen, technology, modern |
| `experience- calligraphy.jpg` | calligraphy, culture, activity |
| `experience-ikebana.jpg` | ikebana, flower, wellness |
| `food- Fish market.jpeg` | fish market, tsukiji, gastronomy |
| `food-kaiseki.jpg` | kaiseki, sushi, luxury dinner |
| `food-yakitori.jpg` | yakitori, teppanyaki, grill |
| `taiko experience.jpg` | taiko, teambuilding, drums |
| `teamlab Tokyo.jpeg` | teamlab, digital art, technology |
| `sakura.jpeg` | sakura, spring, nature |
| `sakura flower.jpg` | sakura, flower, closing |
| `sakura-Tokyo.jpg` | sakura, tokyo, cover |

**Логика выбора:** система ищет фото по совпадению тегов с поисковым запросом слайда. Каждое фото используется только один раз на презентацию (повторы исключены). При нехватке — Unsplash, затем Pexels.
