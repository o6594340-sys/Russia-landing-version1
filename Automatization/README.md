# Automatization

Стратегические документы по автоматизации бизнес-процессов MICE/DMC-деятельности Ольги.

Это не код — здесь только анализ и планирование, из которого выросли конкретные проекты (см. раздел «Связанные проекты» ниже).

## Файлы

| Файл | Что внутри |
|------|-----------|
| [business-analysis.md](business-analysis.md) | Полная схема бизнес-процесса (7 этапов: от первого контакта до ведения проекта), время на каждом этапе, топ-5 кандидатов на автоматизацию с приоритизацией по эффекту/усилиям |
| [process-com-offer.md](process-com-offer.md) | Детальный разбор самого узкого места — подготовки коммерческого предложения под тендер (2–3 дня на всё). 5 инструментов для ускорения цикла с 3–5 часов до 45–75 минут |

## Ключевая идея

Не ждать ответа DMC (24–48 часов) — готовить черновик предложения (концепция, активности, структура презентации) параллельно, и просто подставлять цифры, когда DMC пришлёт смету.

## Связанные проекты

Документы здесь — отправная точка. Конкретные инструменты реализованы в соседних папках:

- **Business cards bot** — сбор контактов с визиток в Google Sheets
- **KP Generator (Tozai Tours)** — генератор коммерческих предложений (PPT + Excel)
- **China DMC Platform** — SaaS-платформа для автоматизации КП по Китаю
- **MICE AI Tools** — портфель инструментов: КП-генератор, Trip Bot, редактор текстов
- **MICE Event App** — PWA для инсентив-туров (предложение + event app + бот)
- **Content Maker** — локальный генератор постов для Telegram-каналов
- **MICE Signature** — лендинг агентства
